# Uso de inteligencia artificial

Para la realización de esta prueba utilicé una herramienta de inteligencia artificial como apoyo en los siguientes puntos:

- Ejercicio 2: apoyo para comprender Laravel, identificar los problemas del controlador y revisar las correcciones propuestas, debido a que no tengo experiencia previa con este lenguaje y framework.
- Ejercicio 3: apoyo para realizar una revisión estática de la sintaxis del componente React, comprobar el cumplimiento de los requisitos y corregir errores detectados en el código.
- Ejercicio 4: apoyo para confirmar algunos datos relacionados con autenticación JWT, refresh tokens y comunicación segura entre microservicios, así como para mejorar la redacción de las respuestas.
- Ejercicio 5: apoyo en la redacción y organización de las respuestas de `REFLEXION.md`. Las experiencias, situaciones y decisiones descritas son propias; posteriormente revisé y edité el texto para asegurar que reflejara correctamente mi experiencia.

Verifiqué el contenido revisando cada respuesta, ajustando las partes que no representaban mi experiencia y conservando únicamente información que puedo explicar durante la revisión técnica.
